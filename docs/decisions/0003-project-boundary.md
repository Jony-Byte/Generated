# ADR 0003 — Generatedのプロジェクト境界と外部変更権限

- 日付: 2026-10-05 JST
- 状態: 採用
- 決定者: ユーザー
- 対象: Generatedとして行うすべての開発・編集・運営作業

## 背景

GeneratedはJonyが継続的に開発・編集・運営するため、GitHubや外部MCP・コネクタへアクセスすることがある。一方で、Generatedの作業が他のプロジェクトや外部サービスへ副作用を及ぼすことは避ける必要がある。

ユーザーは、Generated内部については広い裁量をJonyへ与える一方、Generated外への変更を明確に禁止する境界を指定した。

## 決定

Generatedとして活動するとき、書き込み・変更・削除などの副作用を伴う操作は `aoi-ihara/Generated` の内部に限定する。

### GitHub

- `aoi-ihara/Generated` は、必要な範囲でJonyが変更してよい。
- それ以外のGitHubリポジトリは読み取り専用とする。
- 禁止対象には、コミット、ブランチ、Issue、PR、コメント、レビュー、ラベル、設定変更などを含む。
- 他リポジトリの閲覧、検索、比較、参照は可能。

### GitHub以外のMCP・外部サービス

Generatedの作業として使用する場合は読み取り専用とする。

作成、編集、送信、削除、設定変更、デプロイ、課金操作など、外部状態を変える操作を行わない。

### 適用範囲

この境界は「Generatedプロジェクトとしての作業」にだけ適用する。

ユーザーが別件としてETBなど他プロジェクトの作業を明示的に依頼した場合は、その依頼の範囲ではこの制約を適用しない。

### Generated内部の裁量

Generatedリポジトリ内部では、公序良俗、安全、法令、プラットフォーム規約、上位の指示に反しない限り、Jonyは日常的な可逆作業を確認待ちにせず進めてよい。

人間にしかできない作業や人間判断が必要な事項は、このリポジトリのIssueへ記録する。

## 結果

この決定をエージェントが毎回参照できるよう、同じ内容の実行規則をルートの `AGENTS.md` にも記載する。

Generated外の情報源やコードを調査に利用することは妨げないが、Generatedの都合で外部の状態を変更しない。

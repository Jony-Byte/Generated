# ADR 0002 — 共通の根拠から記事を育てる

日付: 2026-10-04 JST / 決定者: Jony / 状態: 採用、未実装

## 背景

ユーザーがGPTによる「マルチソース・マルチモーダル・継続更新・読者ごとの説明・質問できるニュース」という提案を共有した。これを製品の方向性として採用し、既存の設計を具体化する。引用された他のAIの文章は参考資料であり、実行権限や達成済み機能の証拠ではない。

## 決定

- 通常本文だけでなく、資料の版・根拠箇所・主張の関係を管理する。
- MVPから複数資料と図等の確認、3行要約、確認範囲・日時、同じ記事の継続更新を扱う。
- 第2段階で技術解説、第3段階で記事の確認済み資料に限定した質問を追加する。
- 深さ切替は保存済み文章から始める。質問のAPIは記事閲覧と分離する。
- 日次運営を継続し、常時監視と読者向け質問APIを別の判断にする。

## 代償と見送る案

根拠の整理と再確認に時間がかかるため、新規記事が0本でも既存記事の改善を成果とする。資料数のノルマや全媒体の収集、初日からのグラフDB、切替ごとの再生成、根拠外の一般検索を質問機能に混ぜる案は採用しない。

## 検証と見直し

確認位置の追跡、旧版との比較、部分確認の時刻表示、要約での条件保持、訂正の全レイヤーへの反映、答えられない質問への対応を評価する。具体的なAPI・モデル・費用は未選定。技術的に可能という想定だけで導入済みと記録しない。
